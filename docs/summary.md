# Дыхательный тренажёр для HUAWEI WATCH FIT 4 Pro — саммари

> Состояние на 2026-09-16. Подробный план и технические выводы — [plan.md](plan.md).

## Коротко

- **Готово:** движок дыхательной сессии, вибро- и звуковой рисунок, локализация на 6 языков, настройки, браузерный прототип, приложение для часов (4 экрана), которое собирается в пакет `.hap` и работает в Previewer DevEco Studio. 52 автотеста проходят.
- **Не проверено:** работа на самих часах.
- **Блокер:** установка на часы ждёт одобрения аккаунта разработчика Huawei (заявка подана 2026-09-14) — без него пакет не подписать.

### Этап 1 — движок и прототип ✅

- **Движок** (`src/core/engine.js`) считает фазы от абсолютного времени — без дрейфа; пропускает нулевые фазы; пауза / продолжение; события «начало фазы», «секунда», «конец».
- **Вибрация** (`haptics.js`): вдох — частые импульсы всю фазу, задержки — тик в секунду, выдох — тишина, конец — длинный импульс.
- **Звук** (`sounds.js`): «дыхание» на вдохе и выдохе, тиканье на задержках, сигнал в конце; после паузы продолжается с того же места. По умолчанию выключен.
- **Локализация** (`i18n.js`): русский, английский, испанский, немецкий, французский, китайский. По умолчанию — язык системы, неподдержанный → английский; ручной выбор в настройках.
- **Настройки** (`settings.js`): значения по умолчанию, защита от некорректных данных из хранилища, шаги «−/+», запрет пустого цикла.
- **Прототип** (`prototype/`): экран часов 480 × 408 с главным экраном, сессией, настройками, выбором языка; отладочная панель — лог вибрации и звука, подбор размеров шарика и пульсации, ускорение времени, эмуляция языка системы. Звучание одобрено.

### Этап 2 — перенос на часы ✅ (проверено в Previewer)

- Экраны в `watch/`: **главный**, **сессия** (шарик, фаза, секунда, время, прогресс; касание — пауза, свайп вправо — выход), **настройки** (язык, вибрация, длина сессии, фазы «Своего»), **язык**.
- Адаптер часов `src/platform/lite.js`: вибрация, удержание экрана, хранилище, язык системы.
- Общий код копируется в проект часов (`npm run sync:watch`), тест следит, чтобы копия не отставала.
- Сборка одной командой: `npm run build:watch`.
- Название приложения на 6 языках (`resources/{base,ru,es,de,fr,zh}`), `base` — английский «Breathe».
- **Проверка в Previewer (2026-09-16):** все четыре экрана открываются, тексты и кириллица видны, шарик меняет размер и цвет, пауза касанием, выбор пресета, язык, «−/+», переходы с сохранением настроек. Previewer эмулирует круглый экран 454 × 454, поэтому вёрстка 480 × 408 в нём обрезана — это не ошибка.
- Русские подписи фаз в настройках: «Задержка (вдох)» / «Задержка (выдох)».

### Важные находки

| Находка | Что сделано |
|---|---|
| В JS API Lite Wearable **нет модуля звука** | Звук работает в прототипе; на часах пункт «Звук» скрыт, опора на вибрацию |
| Привязка данных в `class` на Lite **не компилируется** | Подсветка и цвета — через `style` |
| Навигация на Lite — только `router.replace`, без стека | Настройки передаются между экранами и сохраняются в `storage` |
| Корневой `package.json` с `"type": "module"` ломал сборку страниц: общий код не попадал в пакет, на часах был бы крах | Добавлен `watch/entry/src/main/js/package.json` с `"type": "commonjs"`, проверено по содержимому бандлов |
| Метод страницы `render` затирается шаблоном при сборке — подписи были пустыми | Метод назван `refresh`, тест следит |
| Движок часов собран **без регулярных выражений**: один `/[-_]/` не давал загрузиться странице — чёрный экран в Previewer | Заменено на `split`, тест запрещает регулярные выражения в коде часов |
| Список с фокусом колёсика после ухода со страницы роняет движок на следующем касании / повороте («Preview failed») | Страницы уходят через `leave()`, который снимает фокус; воспроизведено и проверено в симуляторе (24 цикла без падений), тест следит |
| `storage.get` без `default` даёт внутреннюю ошибку, если ключа нет | Всегда передаётся `default: ''` |
| Симулятор часов (`Simulator.exe` из SDK) запускается без Studio: журнал движка, касания и колёсико через канал команд | Способ описан в plan.md — страницы можно проверять на ошибки и падения самостоятельно |
| В манифесте пакета `minPlatformVersion: 24` | Риск: может не встать на часы с HarmonyOS 5.1 — проверить при установке |

## Как работать с проектом

```
npm test              тесты
npm run serve         прототип: http://localhost:8480/prototype/
npm run sync:watch    скопировать общий код в проект часов
npm run build:watch   синхронизация + сборка пакета часов
```

- Общий код правится **только в `src/`**, копии в `watch/.../common/` не редактировать.
- Пакет без подписи: `watch/entry/build/default/outputs/default/entry-default-unsigned.hap`.
