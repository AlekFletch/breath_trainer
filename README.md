# Дыхательный тренажёр для HUAWEI WATCH FIT 4 Pro

Приложение для часов: настраиваемые фазы дыхания (вдох / задержка / выдох / задержка),
анимированный шарик, вибрация в такт, общее время сессии.

## Состояние

- **Этап 0 — проверка установки:** DevEco Studio стоит, проект `watch/` собирается, DevEco Assistant видит часы. Ждём одобрения аккаунта разработчика для подписи и установки.
- **Этап 1 — движок и прототип:** сделан. Движок, вибро-рисунок, отображение и локализация покрыты тестами; прототип 480 × 408 в браузере.
- **Этап 2 — перенос на часы:** экраны главный / сессия / настройки / язык в `watch/`, пакет собирается, в Previewer DevEco Studio все экраны работают. Проверка на часах — впереди.
- **Языки:** русский, английский, испанский, немецкий, французский, китайский. По умолчанию — язык системы, если он не поддержан — английский; в настройках можно выбрать вручную.
- **Звук:** звук вдоха и выдоха на всю фазу, тик на каждой секунде задержек, сигнал в конце. По умолчанию выключен, включается на главном экране и в настройках. В прототипе синтезируется в браузере; на часах — только если найдётся аудио-API (в JS API Lite Wearable модуля звука нет, см. риски в плане).

План: [docs/plan.md](docs/plan.md)

## Команды

```
npm test              тесты (node:test, без зависимостей)
npm run serve         прототип на http://localhost:8480/prototype/
npm run sync:watch    скопировать общий код в проект часов
npm run build:watch   sync:watch + сборка debug-пакета часов (hvigor из DevEco Studio)
```

## Технические вводные

| Параметр | Значение |
|---|---|
| Устройство | HUAWEI WATCH FIT 4 Pro, HarmonyOS 5.1, класс **Lite Wearable** (LiteOS) |
| Экран | **408 × 480** (ширина × высота), AMOLED, прямоугольный, вертикальный |
| Стек | JS + HML + CSS (ArkUI.Lite). ArkTS для этого класса устройств **не поддерживается** |
| IDE | DevEco Studio, шаблон Lite Wearable |
| Установка | DevEco Studio → `.hap` → телефон (`/sdcard/haps/`) → DevEco Assistant + Huawei Health по Bluetooth → часы |
| Телефон | не-Huawei Android |

## Структура репозитория

```
docs/plan.md           план разработки и конкретика по установке
src/core/engine.js     автомат сессии от абсолютного времени: фазы, события phaseStart / secondTick / end, пауза
src/core/haptics.js    рисунок вибрации: вдох — импульсы inhalePulseHz, задержки — тик в секунду, выдох — тишина, конец — long
src/core/view.js       масштаб шарика, цифра, формат времени
src/core/presets.js    4-7-8, квадрат, расслабление, «своё»
src/core/sounds.js     звуковые команды: вдох / выдох на всю фазу, тик на секундах задержек, финал
src/core/session.js    связка движок + вибрация + звук + платформа
src/core/i18n.js       строки на 6 языках, выбор языка: настройка → язык системы → английский
src/core/settings.js   настройки: значения по умолчанию, проверка данных из хранилища, шаги «−/+»
src/platform/lite.js   адаптер часов: @system.vibrator / brightness / storage / configuration, без звука
src/platform/web.js    адаптер браузера
prototype/             экран часов 480 × 408 + отладочная панель (вибрация, подбор параметров, ускорение времени, эмуляция языка системы)
test/                  тесты
scripts/               сервер прототипа, синхронизация и сборка часов
watch/                 проект DevEco Studio (Lite Wearable)
  entry/src/main/js/MainAbility/
    pages/             index · session · settings · language (HML + CSS + JS)
    common/core/       копия src/core — генерируется npm run sync:watch, руками не править
    common/platform/   копия src/platform/lite.js
    common/watch.js    помощники страниц: настройки между экранами, переводчик, переходы
```

Код в `src/` написан в синтаксисе ES5 с `export`, чтобы без изменений работать в JS-рантайме ArkUI.Lite.
Переводы живут в `src/core/i18n.js`, а не в `$t`-файлах ArkUI: `$t` всегда следует языку системы и не переключается внутри приложения.
Общий код правится только в `src/`; тест `watch-sync` падает, если копия в `watch/` отстала.
